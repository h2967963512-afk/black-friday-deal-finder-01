**FridayFinds** — a Black Friday 2026 deal finder with 24 real deals, every price checked on Friday, Nov 27, 2026 at the store itself (or in a deals source that names the store), with an honest verdict on each: new low, strong deal, solid deal, or small cut. Search, filter by category, store, discount and verdict, sort by discount, dollars saved or verdict, compare the same product across stores, and open any deal at its store.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. `main.ts` hands the site in: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
